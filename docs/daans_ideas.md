# Daan's feature ideas

## 1. Sound effects and celebrations

Add audio and visual feedback to key game moments to match the lively bar/cafe atmosphere of Toepen.

### Sound effects
- Sound when a player hits Pelt (14 points).
- Sound when a player gets knocked out (≥15 points).
- Sound when someone knocks (toeps).
- Sound when the game is won (last player standing).

### Celebratory screen after each game
- When a game finishes, show a full-screen celebration for the winner.
- Display the winner's name prominently with animations (confetti, trophy, or similar).
- Show a summary: pot amount won, final scores, number of buy-ins.
- Include a "Start New Game" call-to-action on the celebration screen.
- All connected clients see the celebration simultaneously via realtime sync.

---

## 2. Player rankings and leaderboards

Persistent rankings for players across games and tournaments.

### Tournament leaderboard
- Ranks players within a single tournament by their cumulative balance (winnings minus losses).
- Updates after each game finishes.
- Visible on the tournament page.

### Overall leaderboard
- Ranks players across all tournaments they've participated in.
- Tracks aggregated stats: total games played, games won, total winnings/losses, win rate.
- Accessible from the main app (not tied to a single tournament).
- Player identity is matched by name (MVP) or by account (post-MVP when accounts exist).

---

## 3. Optimize for narrow screens

The app should be optimized for one-handed phone use during a card game. Players glance at their phone briefly — the UI must be scannable and operable without precision tapping.

### Layout changes
- Minimize horizontal scrolling — all players should fit on screen without swiping where possible.
- Use large tap targets suitable for quick, one-handed interaction (e.g. the point-count button per backlog).
